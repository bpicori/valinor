# Memory

Long-term memory for future sessions.

Edit this file directly using read_file + edit_file / write_file.

Use clear `## Section` headings for durable facts (preferences, conventions, important details about the user or project).

Daily notes can go in `memory/daily/YYYY-MM-DD.md`.

Background dreaming may consolidate this file from recent sessions. Dream reports are written to `memory/dreams/`.
